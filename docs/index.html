Ridge — No Cold Start

The accountability agent that remembers what your friends verified.

Habit apps track behavior; they don't understand it. Nothing notices that you always fail on Sundays, and week three gets the same reminder as week one. Ridge is what it looks like when an accountability app gets a memory — and its memory is built from a signal almost no product has: on REACH, our shipped social-accountability app, peers verify photographic proof of every rep. Ridge learns from what real humans confirmed, not from self-report.

repo · everything here was built during the hack; REACH is the pre-existing environment, reached only over its public HTTP API

01 · The demo, under the hood

Four beats — and what each one proves

1
"Check on Carla and act." One chat message triggers a full deliberation: Ridge reads her streaks, proof posts, and the verification diary through the MCP server, then writes what it learns to MongoDB.
Proves: agent memory formed from live application data. Every observation stored carries evidence pointers (post:4293, date:2026-08-09); the storage layer refuses one without.
2
The real app changes. In REACH's feed, a 🤖 Ridge comment lands on a real post; where the pattern warrants it, a recovery challenge appears, built around Carla's actual failure mode. Ridge discovered that mode unprompted: her only streak breaks fall on week edges (Sun 8/09, Mon 8/03 — true in the seeded data).
Proves: the agent acts through the app's own API, under the same rules as the mobile client. No privileged writes.
3
Kill it mid-thought. A deliberation is running in the terminal; Ctrl-C kills it. The same command again prints [resume] and continues from the exact node it died at.
Proves: LangGraph checkpoints every step to MongoDB. State survives the process. No cold start.
4
Show the receipts. The live memory viewer lists every belief with the evidence chain that produced it — each one traceable to posts real people verified.
Proves: the memory is auditable. "Why did you say that" is a click, not a mystery.
02 · The loop

The feedback loop closes through people

Enforced in code, not prompt Ridge never verifies proof and never posts it — humans do. Its only self-executed writes: a peer nudge, an in-app comment, at most one pattern-warranted recovery challenge. Everything else is a proposal. Agent plans; people judge.

04 · MongoDB, concretely

Six kinds of memory, one Atlas cluster

storecollectionwhat it changes
episodicobservationsFacts with mandatory evidence pointers into REACH — evidence-free memories are refused at the storage layer
semanticbeliefsThe working model of the person, read into every plan
narrativestoriesPer-user history — "three weeks in, don't stop now," not "you missed a post"
auditrunsEvery deliberation: what it read, concluded, did
statecheckpointsKill-and-resume mid-deliberation
conversationtranscriptOne persistent thread — voice and text share it, per app user

Stack: MongoDB Atlas · LangGraph + langgraph-checkpoint-mongodb · OpenRouter · ElevenLabs Agents (expressive) · MCP (FastMCP + langchain-mcp-adapters) · Python 3.11.
